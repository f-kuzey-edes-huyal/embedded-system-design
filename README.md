# Embedded System Design (Arduino)

This repository contains Arduino (.ino) examples and exercises used in the Embedded System Design course.

## Topics
- Digital I/O (LED, Button)
- Timing (delay, millis)
- Finite State Machines (FSM)
- Basic sensors
- Serial communication

## Requirements
- Arduino IDE
- Arduino Uno (or Wokwi simulator)

## How to run
1. Open Arduino IDE
2. Go to File → Open
3. Select the `.ino` file
4. Upload to Arduino board
